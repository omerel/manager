# מצגת Helm — הצעה לפיילוט

| קובץ | מה זה |
|---|---|
| `Helm - הצעה לפיילוט.pptx` | המצגת עצמה, 18 שקפים. כל אובייקט הוא אובייקט PowerPoint אמיתי — טקסט, טבלאות וצורות — כך שאפשר לערוך הכול. |
| `build.mjs` | המחולל. הקובץ ה-pptx נוצר ממנו, לא נערך ידנית. |
| `helm-deck.html` | אותו תוכן כדף HTML יחיד (RTL), לתצוגה בדפדפן. |

## לייצר מחדש

```bash
cd presentation
npm install      # דורש רשת — pptxgenjs מ-npm
npm run build
```

עריכה ידנית ב-PowerPoint לא חוזרת ל-`build.mjs`. אם שינית שקף בקובץ ובנית מחדש —
השינוי יידרס. תיקונים שאמורים להישמר צריכים להיכנס ל-`build.mjs`.

זהו חומר שיווקי בלבד; אינו חלק מהאפליקציה ואינו נכנס לדימוי המשלוח.
